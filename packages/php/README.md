# Rehearsal for Laravel

**Parallel Playwright testing for Laravel**

`sti3bas/rehearsal` provisions isolated Laravel state for native Playwright workers. It supports Laravel 13 on PHP 8.3+, with SQLite, MySQL, and PostgreSQL, plus opt-in Mailpit, Scout, and Reverb integrations. Install it as a development dependency alongside the `@sti3bas/rehearsal` npm package.

The packages are not published yet. See the [project README](https://github.com/Sti3bas/rehearsal#readme) for the runnable starter, installation path, and integration examples.
